🔗 การเชื่อมต่อ

เปิดแอป Chat Hub → ⚙ ตั้งค่า → กล่อง "ส่วนเสริม KengAmp ผู้ช่วยร้าน" → กด คัดลอก ลิงก์ แล้ววางที่นี่ (ใช้ร่วมกันทั้ง 2 งาน · ห้ามเผยแพร่ลิงก์)

💬 แชท (Chat Hub)


ดึงแชททุก 1 นาที · ส่งเฉพาะข้อความ/รูปที่คุณตอบใน Chat Hub (เช็กคิวทุก 30 วินาที) · ห้ามปิดแท็บแชท Shopee / Lazada ที่ปักหมุดไว้

🟢 งานเบื้องหลัง (POS · สิ่งที่ต้องเปิด / ทำ)


ถ้ามีหลายโปรไฟล์ Chrome (เช่น โปรไฟล์ร้าน Keng77) ให้ติ๊กข้อนี้ไว้แค่ในโปรไฟล์หลัก โปรไฟล์อื่นเอาติ๊กออก (และเอาติ๊ก Lazada ในหมวดแชทออก) จะได้ไม่เปิดหน้าซ้ำกัน

ตัวดึงข้อมูลยังเป็นสคริปต์ Tampermonkey เดิม (ต้องติดตั้งไว้ใน Chrome นี้) · ส่วนเสริมเปิดหน้า → รอจนเสร็จ → ปิดแท็บเอง · ติดรหัสผ่าน/หลุดล็อกอินเกิน 20 นาที จะแจ้งเตือนและปล่อยแท็บไว้ให้จัดการ
